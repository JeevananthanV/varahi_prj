# Zayed Sustainability Prize — Setup Guide

Welcome to the **Zayed Sustainability Prize Web Portal** setup guide. This bilingual web platform is built with React 18 and Vite.

- **GitHub Repository**: [https://github.com/JeevananthanV/varahi_prj](https://github.com/JeevananthanV/varahi_prj)
- **Author**: Jeevananthan V

---

## 📋 System Prerequisites

- **Node.js**: v18.0.0 or higher
- **npm**: v9.0.0 or higher
- **Git**: v2.30.0 or higher

---

## 📥 1. Clone the Repository

```bash
git clone https://github.com/JeevananthanV/varahi_prj.git
cd varahi_prj
```

---

## 📦 2. Install Dependencies

```bash
npm install
```

---

## 🚀 3. Run Development Server

```bash
npm run dev
```

Open `http://localhost:5173` in your browser.

---

## 🏗️ 4. Production Build

```bash
npm run build
npm run preview
```
Output files will be generated in `dist/`.
